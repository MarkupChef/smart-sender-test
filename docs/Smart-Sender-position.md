# Smart Sender

# **Про вакансію**

**Про Smart Sender**

Smart Sender — платформа автоматизації маркетингу та комунікацій, яка допомагає бізнесу вибудовувати діалог із клієнтами в Telegram, Viber, Instagram, WhatsApp, Facebook Messenger: чат-боти, розсилки та сценарії взаємодії будь-якої складності. Платформа не обмежена типом бізнесу й однаково ефективна як для B2C, так і для B2B. Сьогодні вона обслуговує понад 400 млн контактів і обробляє мільярди повідомлень.

Ми створюємо нове покоління продукту — Smart Sender 2.0. Серверна частина вже працює на мікросервісній архітектурі, API повністю задокументоване у форматі OpenAPI, дизайн підготовлено. Тепер ми шукаємо фахівця, який закладе клієнтську частину з нуля та стане відповідальним за її розвиток.

**Ваша роль**

- Проєктування архітектури фронтенду: монорепозиторій, типізований API-клієнт на основі OpenAPI, авторизація та бібліотека UI-компонентів відповідно до дизайну у Figma.
- Розробка клієнтської частини платформи: авторизація та керування акаунтом, робота з проєктами, контактами, розсилками, чат-ботами, аналітикою та інтеграціями з месенджерами.
- Ухвалення технічних рішень і формування стандартів розробки у фронтенді.
- Після закладання архітектури — участь у наймі та розвитку фронтенд-команди.
- Надалі — створення візуального конструктора сценаріїв на основі блоків (node-based editor) та мобільного застосунку на React Native.

**Що для нас важливо**

- Від 5 років комерційного досвіду з React (або менше — за наявності досвіду запуску продукту з нуля).
- Впевнене володіння TypeScript (strict mode).
- Досвід роботи з Vite, TanStack Query, react-hook-form + zod або аналогічними рішеннями.
- Розуміння механізмів cookie-авторизації, CORS, CSRF та same-site.
- Досвід створення фронтенду з нуля — самостійно або в складі невеликої команди.
- Здатність працювати автономно: планувати задачі та доводити їх до продакшену.

**Буде перевагою**

- Досвід розробки node-based редакторів (React Flow або аналоги).
- Досвід з React Native / Expo.
- Tailwind CSS, Radix UI / shadcn/ui.
- Vitest, Playwright.
- Досвід локалізації інтерфейсів (i18n).
- Використання AI-інструментів у розробці (Claude Code, Cursor).
